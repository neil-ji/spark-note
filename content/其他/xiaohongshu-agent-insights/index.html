核心价值

方向 1 并不复杂。它的意义在于——自动化 Coding 之后，自动化测试是最后一块缺失的拼图。 这个组合恰好补齐了它。LLM 驱动逻辑、Browser 执行操作、VLM 判断结果，三个组件各自成熟，拼在一起就是 E2E 测试的工业化答案。

为什么是现在

自动化 Coding 已相对成熟，测试成为瓶颈。三个组件的成本曲线同时在 2025–2026 进入可用区间——LLM 推理足够便宜、浏览器自动化足够稳定、视觉理解足够准确。组合门槛消失。

未来 Agentic 工具必然沿 两个维度 分化
人机心流对话 — 高维决策领域，Human in the Loop 是核心
机器自动化执行 — 规模化 + 高效率，「能用 + 廉价」是唯一前提

机器自动化执行

规模化与高效率是关键词。

「低成本 + 可用」在这里发挥最大价值。

「可用」已被一线甚至二线模型攻破。工业化前提只有两点：能用 + 廉价。

随着模型越来越强，Agentic 工具的 Harness 设计已被 模型内化。 未来架构将趋向 Pi Agent 式轻量设计。

方向二 · 方法论实验

人类方法论 × Agent
Re-act Loop

金字塔结构能否提升生成质量？
灵感来源

整理书架翻到《结构思考力》（李中秋）—— 这套通用逻辑思维框架，能否让 Agent 用起来？ 基于此设计了一套 MCP tool，在 Re-act Loop 中让 Agent 自主调用工具完成金字塔结构的构建：问题定义 → 逐层分解 → 重要性排序 → 归纳结论。

测试场景：竞品分析  ·  复杂代码重构

金字塔结构
损失信息密度，多轮 Tool Use 拉长链路，Token 消耗约为基线的 2–3 倍，但输出质量无显著提升
无金字塔（基线）
信息密度高，追问「总结提炼」即可达到类似的结构化效果，更灵活且 Token 效率更高

根本原因：金字塔结构解决的是分散人脑认知负荷—— LLM 没有这个瓶颈。拉长对话、增加中间步骤反而导致上下文稀释，生成质量不升反降。

多轮输出 + 思维链 + Tool Use → Token 消耗远超基线，性价比低
人类认知瓶颈 ≠ 模型瓶颈，直接套用人类框架可能适得其反
好的 Agent 设计应发挥模型优势，而非模拟人类思维路径

小结

两个方向，
两个结论

1

方向一：确定性强的工业化路径

LLM + Browser + VLM 组合廉价可用，E2E 自动化测试的工业化前提已经具备。 未来半年重点是降本而非提稳。Agentic 工具朝两个维度分化—— 心流对话（Desktop 体验为王）和自动化执行（便宜+能用为王）。

2

方向二：否定性结论也是收获

并非所有人类方法论都适合迁移到 Agent。人类的认知瓶颈 ≠ 模型的瓶颈。 金字塔结构解决的是人脑负荷问题，LLM 没有这个限制——强行套用人类框架， 反而拉长链路、增加 Token 消耗，质量不升反降。
